# Canada Planning Facts

**Prototype. AI-assisted. Reference data: verify at the source. Education, not advice.**

Hand-verified Canadian planning figures (account limits, CPP and OAS parameters, federal and Ontario brackets, RRIF factors), each with its official source, tax year, the date it was read and its status, served to AI assistants as a local MCP server and an Agent Skill. Values not yet published come back as "not yet published", never a guess.
